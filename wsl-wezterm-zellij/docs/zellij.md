# Zellij編: ターミナルの中でウィンドウ管理をする

Zellijは「1つのターミナルの中に、複数の画面(ペイン)や作業単位(タブ)を作れるツール」。
VSCodeで言うと「ウィンドウ分割 + ウィンドウタブ + ワークスペース切り替え」をターミナルの中で
やっていると思えばいい。

このページのキーバインドは`zellij setup --dump-config`で実際に確認した、この環境の
**デフォルト設定そのまま**(このリポジトリでは独自にキーを変更していない)。

## 最初にこれだけ覚える

| したいこと | キー |
|---|---|
| 隣のペインに移動する | `Alt` + `矢印キー`(または`h`/`j`/`k`/`l`) |
| 新しいペインを作る | `Alt` + `n` |
| ペインを閉じる | `Ctrl+p` → `x` |
| タブを切り替える | `Alt+i` / `Alt+o`(左右に移動) または `Ctrl+t` → `矢印` |
| 新しいタブを作る | `Ctrl+t` → `n` |
| コピーしたい(範囲選択) | **マウスでドラッグするだけ**(離せば自動コピー) |
| セッションから抜ける(プロセスは残る) | `Ctrl+o` → `d` |
| 詰んだ・訳が分からなくなった | `Ctrl+g`を押す(→操作を無効化する「ロック」を解除。後述) |

Zellijは「まず`Ctrl+文字`でモードに入り、そのあと1文字を押す」という**2段階操作**が基本。
VSCodeのショートカットに慣れていると「なぜ2回押すのか」と感じるが、これはtmuxやscreenと
同じ伝統的な設計。ただし**マウスも普通に使える**(`mouse_mode`はデフォルトで有効)ので、
慣れないうちはクリックやドラッグに頼っても全く問題ない。

## 基本概念: セッション・タブ・ペイン

```
セッション(例: "py")
 └─ タブ "work"
     ├─ ペイン: nvim (エディタ)
     └─ ペイン: shell (ターミナル)
 └─ タブ "monitor"
     └─ ペイン: btop (リソースモニタ)
```

- **セッション**: VSCodeの「ウィンドウ全体」に相当。この環境では`zj`/`zj py`/`zj tex`が
  それぞれ`plain`/`py`/`tex`という名前の固定セッションを作る/繋ぎ直す
- **タブ**: セッションの中の作業単位。画面上部のバーに表示される
- **ペイン**: 1つのタブの中をさらに分割したもの。VSCodeの画面分割に一番近い

### この環境で実際に使われているレイアウト

`zj py`(Python-Workコンテナ)・`zj tex`(LaTeX-Workコンテナ)は次の構成:

```
work タブ:    [ nvim (左75%) | shell (右25%) ]
monitor タブ: [ btop ]
```

`zj`(コンテナなしのplainレイアウト)はタブ分けせず:

```
[ nvim (左75%) | shell (右25%) ]
```

エージェント指定(`zj py claude`など)をすると3番目(plainなら2番目)に`agent`タブが
追加される。詳細は[`workflows.md`](./workflows.md)を参照。

## シチュエーション別実例

### 「編集中のファイルの隣でコマンドを打ちたい」(VSCodeの`Ctrl+@`感覚)

`zj py`/`zj tex`/`zj`はどれも最初から`nvim`ペインの右(または下)に`shell`ペインが
用意されている。**新しく作る必要はない**。

1. `Alt+l`(または`Alt+右矢印`)でシェルペインに移動
2. コマンドを打つ(`python sample.py`、`git status`など)
3. `Alt+h`でnvimペインに戻る

これがVSCodeの「エディタと統合ターミナルを行き来する」に対応する、この環境での標準の流れ。

### 「もう1枚シェルが欲しい」

1. `Alt+n`(新しいペインを右側に開く)、または`Ctrl+p` → `d`(下に開く)/`r`(右に開く)
2. 不要になったら、そのペインにフォーカスした状態で`Ctrl+p` → `x`(閉じる)

### 「1つのペインを画面いっぱいに広げて集中したい」(VSCodeの`Ctrl+K Z`ズームモード相当)

`Ctrl+p` → `f`(フルスクリーン切り替え)。もう一度押すと元のレイアウトに戻る。

### 「ペインが小さすぎる/大きすぎる」

`Ctrl+n`でリサイズモードに入り、`h`/`j`/`k`/`l`(または矢印)でその方向に広げる。
`Enter`か`Esc`で通常モードに戻る。マウスでペインの境界線をドラッグしてもよい。

### 「monitorタブでリソース(CPU/メモリ)を見たい」

`zj py`/`zj tex`なら、`Alt+o`(次のタブへ)で`monitor`タブに移動すると`btop`が動いている。
コンテナ内の負荷(コンパイル中など)を確認するのに便利。`Alt+i`で`work`タブに戻る。

### 「コピー&ペーストしたい」

VSCodeの`Ctrl+C`/`Ctrl+V`とは操作感が違うので注意。

- **コピー**: マウスでテキストをドラッグして選択 → 離すと自動でクリップボードにコピーされる
  (`copy_on_select`がデフォルト有効)
- **貼り付け**: ターミナルなら右クリックまたは`Shift+Insert`など、WezTerm側のペースト操作を使う
  (WezTermの設定に依存)
- キーボードだけで範囲選択したい場合は`Ctrl+s`(スクロールモード)→ `Ctrl+s`をもう一度で検索、
  または単純にマウス選択が一番早い

**ホストの`zj`(plainレイアウト)だけ** `copy_command "clip.exe"`が設定されており、選択すると
Windows側のクリップボードにも届く。コンテナ内(`zj py`/`zj tex`)やSSHサーバーではこの連携は
無い(`../README.md`の既知の制約を参照)。

### 「セッションを閉じずに一旦抜けたい」(VSCodeでウィンドウを閉じても裏でプロセスは続く、に近い)

`Ctrl+o` → `d`(Detach)。nvimもシェルの中で動いていたプロセスもそのまま裏で生き続ける。
再開するときは同じコマンド(`zj`/`zj py`/`zj tex`)をもう一度打てば同じセッションに
繋ぎ直される(このリポジトリの`zj`はセッション名を固定しているため)。

### 「セッションがおかしくなった・元に戻せない」

VSCodeなら「ウィンドウを閉じて開き直す」に相当する操作。

```
zjdel        # zj (plain) のセッションをリセット
zjdel py     # zj py のセッションをリセット
zjdel tex    # zj tex のセッションをリセット
```

そのあと同じ`zj`系コマンドを打てば、レイアウト通りのまっさらな状態で作り直される。
詳しくは`../README.md`の「セッション名は固定・再接続前提」を参照。

### 「`zjdel`しても直らない・そもそも何が悪いのか分からない」

```
zjdoctor
```

chezmoiの差分・ホストの必須ツール・LazyVimのプラグイン/Mason状態・(WSLホストなら)
Docker daemon・各コンテナの起動状態とlazygitの有無・現在のZellijセッション一覧を
まとめてチェックする。`zjdel`はセッションだけをリセットするのに対し、`zjdoctor`は
「そもそも環境自体が壊れていないか」を先に切り分けるための診断コマンド。
`✓`(緑)は正常、`!`(黄)は要確認、`✗`(赤)は必須ツールが無い、を表す。

### 「操作したつもりがnvim側に文字が入力されてしまう/逆に効かない」

Zellijのキーバインド(`Ctrl+p`など)は、フォーカスしているペインの中のアプリより**先に**
Zellijが横取りする。まれにnvimやアプリ側で同じキーを使いたい場面があるので、そのときは:

- `Ctrl+g`で**ロックモード**に入る(Zellij自身のキーバインドを一時的に無効化し、
  すべてのキー入力を素通しでペインの中のアプリに渡す)
- 用が済んだらもう一度`Ctrl+g`で解除

「なんか操作がおかしい」と思ったら、まずロックモードに入っていないか確認するとよい
(画面下のステータスバーにモード名が出る)。

### 「間違えて`Ctrl+q`を押してしまった」

`Ctrl+q`は**Quit**(Zellijクライアント終了)に割り当てられている。VSCodeの`Ctrl+W`
(ウィンドウを閉じる)のつもりで押すと事故になりやすいので注意。セッション自体は
バックグラウンドで生き続けている場合が多いので、慌てず同じ`zj`系コマンドで繋ぎ直せばよい。

### 「新しいプロジェクトを別画面で並行して触りたい」

- 同じコンテナ内で別の作業をしたいだけなら: 新しいタブ(`Ctrl+t` → `n`)
- Python-WorkとLaTeX-Workを両方同時に開きたいなら: 別々のWezTermタブ/ウィンドウでそれぞれ
  `zj py`と`zj tex`を実行する(セッションが別なので完全に独立している)

## リファレンス: よく使うキー一覧

### モードに入るキー(すべて`Ctrl+文字`)

| キー | モード | 抜けるキー |
|---|---|---|
| `Ctrl+p` | Pane(ペイン操作) | `Enter`/`Esc` |
| `Ctrl+t` | Tab(タブ操作) | `Enter`/`Esc` |
| `Ctrl+n` | Resize(リサイズ) | `Enter`/`Esc` |
| `Ctrl+h` | Move(ペイン移動) | `Enter`/`Esc` |
| `Ctrl+s` | Scroll(スクロール・検索) | `Enter`/`Esc` |
| `Ctrl+o` | Session(セッション操作) | `Enter`/`Esc` |
| `Ctrl+g` | Locked(全キー無効化・素通し) | `Ctrl+g` |

### Pane モード(`Ctrl+p`のあと)

| キー | 動作 |
|---|---|
| `h`/`j`/`k`/`l` または矢印 | ペイン間を移動 |
| `n` | 新しいペイン |
| `d` | 下に新しいペイン |
| `r` | 右に新しいペイン |
| `x` | フォーカス中のペインを閉じる |
| `f` | フルスクリーン切り替え |
| `c` | ペインの名前を変更 |
| `w` | フローティングペイン表示切り替え |

### Tab モード(`Ctrl+t`のあと)

| キー | 動作 |
|---|---|
| `h`/`l`(または矢印) | 前/次のタブへ |
| `n` | 新しいタブ |
| `x` | タブを閉じる |
| `r` | タブの名前を変更 |
| `1`〜`9` | 番号でタブへジャンプ |

### モード無しで直接効くキー(`Alt+`)

| キー | 動作 |
|---|---|
| `Alt+矢印` / `Alt+h/j/k/l` | ペイン間を直接移動(モードに入らない) |
| `Alt+n` | 新しいペインを直接作成 |
| `Alt+i` / `Alt+o` | タブを左/右に切り替え |
| `Alt+f` | フローティングペイン切り替え |
| `Alt+=` / `Alt+-` | フォーカス中のペインをリサイズ |

### Session モード(`Ctrl+o`のあと)

| キー | 動作 |
|---|---|
| `d` | Detach(セッションから抜ける。プロセスは残る) |
| `w` | セッションマネージャーを開く |
