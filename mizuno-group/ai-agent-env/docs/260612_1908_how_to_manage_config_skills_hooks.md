# 前提
このリポジトリが Antigravity / Claude Code / Codex の3種エージェントがどれであってもslurmのcompute nodeのapptainerコンテナ内で正常に起動され、対話式・非対話式・自律実験（/goalの利用）が可能な統一フレームワークを目指しているは既に理解しているだろう。

# 現状
- 2026-06-12 19:08現在、ユーザーはagentrun assistでの挙動は全エージェントに対して確認を行い実際にinteractiveに対話が出来ていることを確認した。
- 一方で各エージェントのskillsやhooks、各種設定が適切に適用されているかは一切検証ができていない。
  - 統一フレームワークである以上全エージェントで適切に適用されていることの確証を得ることは**絶対的な要件**である。
- skillsやhooksの追加や削除、編集をした際に影響する（追加で編集しなければならないファイル）範囲が不透明、保守性が最悪
  - 頻繁にアップデートをしたいので出来るだけ簡便でありたい

# 理想形
`common/`は現在のように、
- 全エージェントが利用するAGENTS.mdの大本（もちろんClaude CodeはCLAUDE.mdとして利用）
- hooksの実処理スクリプト
- skills
のみが置かれている状態が理想的である。ここをメインとして編集を行う。
一方で、settings.jsonであったりconfig.tomlであったり、各エージェントの仕様によって異なる設定ファイル群は`agents/xxx/`の下で個別管理を行う。
- ただし、保守性の面でskillsやhooksをcommonで書き換えた際になんらかのコマンドを用いて自動でagents/xxx/下の適用のための設定ファイル群も書き換わってほしい。
各エージェントの設定読み込みの仕様によって変わりえる部分なので、ここは**各エージェントに自分の領域を担当して立て付けを組んでいただきたい**。

# やっていただきたいこと
まず、あなたが
- **Antigravityである場合、Antigravity（agy）の領域のみを**
- **Claude Codeである場合、Claude Codeの領域のみを**
- **Codexである場合、Codexの領域のみを**
担当してください。自分の仕様は自分が最も理解しているでしょう？

1. commonのhooksやskills、AGENTS.md（CLAUDE.md）が適切に全てコンテナ内で起動したエージェントに反映される仕組みとなるようにする
   - 各エージェントは自身の設定ファイル（何を読み込むか）の仕様を確認し、適切にagents/xxx/の下を整理整頓する
   - エージェントによって仕様は異なるので、agents/xxx/の下が他エージェントと大きく異なることは許容するが、コンテナ内への移行の仕方は**出来るだけ簡便に**、非対称性が生じすぎないように
2. commonの編集が各エージェントのagents/xxx/の下に反映されるようなコマンドの作成（agentrun系列）
   - pretooluseやhooksの適用タイミングの面で自動化が難しいところはあるかもしれません。非常に難しいようでしたらそれを私に伝えてください
   - 今回のスコープには入れていないですが、3種エージェントの反映コマンドを最終的に統合したコマンドを作成する予定です
