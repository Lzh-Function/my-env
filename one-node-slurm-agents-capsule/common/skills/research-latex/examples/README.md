# Sample PDFs (synthetic, demonstration-only)

The `previews/` folder contains three real LuaLaTeX-compiled PDFs. They were built using the exact templates under `assets/templates/`, with the shared preamble and Biber processing.

All numeric data and research settings in the PDFs are **synthetic examples**, not experimental results or claims. The cited SMILES source is a real publication, included only to demonstrate bibliography formatting.

These PDFs are for checking the layout before installing TeX Live or choosing a document style; they are not templates to edit directly. Start with `scripts/research_latex.py init --template ...` and modify the generated source files.
